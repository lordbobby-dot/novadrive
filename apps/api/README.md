# NovaDrive API

NestJS backend. See the [root README](../../README.md) for setup and the
[roadmap](../../ROADMAP.md) for architecture/milestone context.

```bash
pnpm --filter api dev            # start in watch mode
pnpm --filter api prisma:studio  # inspect the database
pnpm --filter api test:e2e       # e2e tests (needs Postgres running)
```

Swagger docs: http://localhost:4000/api/docs
